# Study Group Finder

A university peer-learning platform that helps students create, discover, and join study groups.

## Features

- User authentication
- Create and manage study groups
- Join and leave groups
- View group details
- Schedule study sessions and meetings
- Dashboard for study activities
- Calendar and session management
- Notifications
- User profiles

## Tech Stack

### Frontend
- React
- Vite
- React Router
- Tailwind CSS
- Axios
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
